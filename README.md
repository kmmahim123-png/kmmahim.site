# KM Mahim — Public Portfolio & Private Life OS

Modern dual-layer personal command system built with React, Vite, Tailwind CSS, and Lucide Icons.

## 🚀 Key Features

### Layer 1: Public Portfolio & Client Gateway
- **Live "NOW" Status Bar:** Directly synced and updated from the Private Life OS.
- **Projects & Ventures:** Interactive showcase of brands, web systems, and AI workflows (JACKFRU Apparel, Autonomous Life OS, etc.).
- **Service Calculator & Direct Booking:** Client appointment booking form routed straight to the OS inbox.
- **1-Click vCard:** Download contact details directly as `.vcf`.
- **Secret Access Gate:** Triple-click on the logo or press `Ctrl + Shift + L` to access the private layer.

### Layer 2: Private Life OS
- **Multi-Wallet Finance:** Track Hand Cash, bKash, Nagad, and Bank Account balances with cash in/out logging and period filtering.
- **Debt & Loan Tracker:** "কে পাবে / কার কাছে পাবো" receivable and payable ledger.
- **Smart Meal Manager:** Hall/Mess meal counting, deposit logging, and remaining meal days estimation.
- **Habits Tracker:** 5 daily prayers (নামাজ), Minoxidil 30-day bottle tracker, and gym/PR workout logs.
- **Study & Goals Command:** Daily, weekly, monthly, and yearly goals with an integrated 25/5 Pomodoro focus timer.
- **Chulbul Idea Vault:** Rapid startup and tech idea capture with tags, status pipeline, and notes.

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Persistence:** Reactive LocalStorage Engine

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
